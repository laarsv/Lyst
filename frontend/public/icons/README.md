# App icons

Replace the SVG/PNG placeholders with your real brand icons:

- `icon-192.png` — 192×192
- `icon-512.png` — 512×512
- `icon-512-maskable.png` — 512×512 (with safe area padding for adaptive icons)
- `apple-touch-icon.png` — 180×180 (iOS home screen: opaque, no alpha, no own rounding)

For development, the PWA manifest tolerates missing icons (the app still installs but with the
default chrome icon).
